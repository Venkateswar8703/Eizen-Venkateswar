# Data Dictionary: Perpetual Inventory Simulation & Feature Store

This document defines the schema, data types, physical interpretations, and observability constraints for all tables generated by the Hidden Inventory Simulator (`src/simulation/`).

---

## 1. Product Master Table (`data/processed/product_master.parquet`)

Static SKU-level attributes across all 1,600 products in `STORE_0001`.

| Column Name | Type | Unit / Range | Description | Observable by ERP? |
| :--- | :---: | :---: | :--- | :---: |
| `sku_id` | `str` | `SKU_0001` - `SKU_1600` | Unique Stock Keeping Unit identifier | Yes |
| `category` | `str` | 10 Categories | Merchandise category (Produce, HBA, Dairy, etc.) | Yes |
| `aisle_id` | `int` | `1` - `32` | Physical store aisle / bay location | Yes |
| `unit_price` | `float` | $\$0.99 - \$64.99$ | Retail selling price per unit | Yes |
| `unit_cost` | `float` | $\$0.40 - \$45.00$ | Cost of goods sold (COGS) per unit | Yes |
| `unit_margin` | `float` | $\$0.40 - \$22.00$ | Margin: $\text{unit\_price} - \text{unit\_cost}$ | Yes |
| `case_pack_size` | `int` | `4, 6, 8, 12, 24` | Units per shipment carton from DC | Yes |
| `target_shelf_capacity` | `int` | `8 - 96` | Planogram shelf facing capacity | Yes |
| `reorder_point` | `int` | `4 - 24` | SOH threshold that triggers auto-replenishment | Yes |
| `order_up_to` | `int` | `12 - 72` | Target order quantity during reorder cycle | Yes |
| `count_duration_min` | `float` | `0.8 - 3.5` | Standard associate audit duration (minutes) | Yes |
| `is_locked_case` | `bool` | `True / False` | Whether item is secured in locked glass case | Yes |
| `is_dsd` | `bool` | `True / False` | Direct Store Delivery (vendor-stocked) item | Yes |
| `is_perishable` | `bool` | `True / False` | Subject to shelf-life degradation | Yes |
| `mean_daily_demand` | `float` | `0.05 - 18.5` | Latent baseline Poisson rate parameter $\lambda_i$ | Hidden (Ground Truth) |
| `theft_susceptibility` | `float` | `0.001 - 0.08` | Relative theft burst probability parameter | Hidden (Ground Truth) |
| `spoilage_rate` | `float` | `0.000 - 0.05` | Daily fraction of stock spoiled | Hidden (Ground Truth) |

## 2. Daily Time-Series Panel (`data/simulated/store_daily_panel.parquet`)

Granular daily panel at `(sku_id, date)` level for 730 days (104 weeks) $\approx 1.17\text{M}$ rows.

### 2.1 The Observable Layer (What the ML Models & Store Staff See)
| Column Name | Type | Description |
| :--- | :---: | :--- |
| `date` | `date` | Calendar date (`YYYY-MM-DD`, Day 1 to Day 730) |
| `sku_id` | `str` | Product identifier |
| `day_of_week` | `int` | `0` (Monday) to `6` (Sunday) |
| `is_weekend` | `bool` | Weekend indicator |
| `is_holiday` | `bool` | Major retail promotion / public holiday |
| `selling_price` | `float` | Daily effective selling price (reflects promotions) |
| `promo_flag` | `bool` | Indicator if item is on active discount / circular |
| `pos_sales` | `int` | **Observed POS scan sales** (censored by on-shelf availability) |
| `system_on_hand` (`SOH`) | `int` | **Book inventory** recorded in perpetual inventory ledger |
| `system_receipts` | `int` | Quantity received on invoice into store system |
| `audit_event` | `bool` | `True` if a physical cycle count was performed today |
| `audit_recorded_on_hand` | `float` | Audited count value posted by associate (`NaN` if uncounted) |
| `system_adjustment` | `int` | Delta posted to book inventory following count |
| `days_since_last_count` | `int` | Elapsed days $L(i)$ since last cycle count |
| `days_since_last_receipt` | `int` | Elapsed days since last delivery receipt |
| `consecutive_zero_sales` | `int` | Running streak of consecutive days with $S(i,t) = 0$ |

### 2.2 The Hidden / Unobserved Layer (Ground Truth for Simulation & Offline Evaluation)
| Column Name | Type | Description |
| :--- | :---: | :--- |
| `latent_demand` | `int` | True customer demand $D(i,t)$ before stockout truncation |
| `true_on_hand` (`TOH`) | `int` | **True physical inventory** on shelf + active backroom |
| `inventory_gap` | `int` | Ground truth gap $G(i,t) = \text{SOH}(i,t) - \text{TOH}(i,t)$ |
| `is_phantom_stockout` | `bool` | Target flag: $\text{SOH} > 0 \land \text{TOH} == 0$ |
| `true_lost_sales` | `int` | Unmet demand: $\max(0, D(i,t) - \text{TOH}(i,t))$ |
| `theft_loss_units` | `int` | Units removed by shoplifting today |
| `mis_scan_units` | `int` | Units uncounted or mis-scanned at POS |
| `spoilage_units` | `int` | Damaged or expired units discarded unrecorded |
| `receiving_discrepancy` | `int` | Difference between invoice and physical delivery |
| `misplaced_units` | `int` | Units physically in store but lost in wrong location |

## 3. Daily Audit Log Table (`data/processed/historical_audit_log.parquet`)

Audit events generated by the historical legacy ABC audit policy (Training Labels).

| Column Name | Type | Description |
| :--- | :---: | :--- |
| `audit_id` | `str` | Unique audit record identifier |
| `date` | `date` | Date audit was conducted |
| `sku_id` | `str` | SKU audited |
| `associate_id` | `str` | Store associate who conducted audit |
| `duration_minutes` | `float` | Time spent counting the SKU |
| `pre_count_soh` | `int` | Book on-hand immediately before audit |
| `physical_count` | `int` | Physical count entered by associate |
| `posted_discrepancy` | `int` | Recorded error: $\text{pre\_count\_soh} - \text{physical\_count}$ |
| `policy_type` | `str` | `LEGACY_ABC` or `COMPLIANCE_90D` |
