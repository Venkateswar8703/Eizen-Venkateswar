Core Formula

Expected Value of a Count

# Expected Net Value of counting SKU i on day d
EV(i, d) = P(gap) × RecoveryRate(category)
          × PersistenceDays × DailyDemand
          × (UnitMargin + BasketAbandonmentLoss − SubstitutionSalvage)
          − LaborCost(count_duration_min)
          − FalsePositivePenalty

# Coefficients are calibration assumptions — not empirically measured facts
End-to-End Implementation

8 Implemented Modules

All modules below are implemented and tested (28/28 unit tests passing). The 2,000-store scale architecture is proposed, not implemented.

MODULE 01
Generative Simulation
Realistic inventory dynamics: compound Poisson theft bursts, perishable spoilage, DSD vendor drops, receiving errors, backroom misplacement, regime shifts.
✅ Implemented
MODULE 02
Statistical Diagnostics
ADI/CV² intermittency classification, Negative Binomial / ZIP distribution fitting, zero-streak tail probability tests, CUSUM change-point detection.
✅ Implemented
MODULE 03
Demand Forecasting
Seasonal Naive → Croston/SBA/TSB → LightGBM multi-quantile. Censoring-aware training downweights phantom-stockout observations ×10.
✅ Implemented
MODULE 04
Gap Prediction & ML
Heuristics → Logistic Regression → Calibrated LightGBM (champion) → DLinear baseline → Aisle Graph Relational (GNN). GNN negative result documented honestly.
✅ Implemented
MODULE 05
Economic Value Engine
Dollar value of each potential count. Sensitivity analysis across wages, recovery rates, and persistence horizons. Coefficients are calibration assumptions.
✅ Implemented
MODULE 06
Workforce Optimisation
OR-Tools CP-SAT integer programming (primary) + Greedy heuristic (baseline). 7-day rolling plan: 3 associates, 240 min/day total, 4-min aisle setup, 90-day compliance.
✅ Implemented
MODULE 07
Scale Design & Closed-Loop Bias
ε-greedy bandit simulation (implemented). 2,000-store distributed architecture documented as proposed — not deployed.
📐 Partially Proposed
MODULE 08
Streamlit Dashboard
9-tab interactive application. All metrics derived from generated pipeline artifacts — no hard-coded performance numbers.
✅ Implemented
Module 06 — Constraint Summary

Workforce Optimisation Constraints

⏱️
Labor Budget
240 usable minutes/day TOTAL across 3 associates
= 80 min per associate
🚪
Aisle Setup Cost
4-minute setup overhead per distinct aisle visited per associate per day
📋
Compliance Floor
Each SKU must be physically counted at least once every 90 days
🔢
Uniqueness
At most 1 count per SKU per 7-day rolling horizon (no repeat audits)
🔗
Aisle Linking
A SKU can only be counted if its aisle is activated — non-separable setup cost
⚖️
Workload Balance
Associate daily minutes must not deviate from team mean by >20 min (soft)
